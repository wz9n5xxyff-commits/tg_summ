# Навык Алисы «Ясно Понятно»

Голосовой навык для колонки с Алисой: пересказывает еженедельный дайджест канала @yasnovolkova.

## Как это работает

```
каждое воскресенье 18:00 UTC (21:00 МСК)
  Задача Claude Code ──► python main.py
                           ├─ читает канал t.me/s/yasnovolkova
                           ├─ Gemini пишет дайджест
                           ├─ публикует его в Telegram-канал
                           └─ кладёт голосовую версию в бакет Object Storage (digest.json)

«Алиса, запусти навык Ясно Понятно»
  Яндекс Диалоги ──► функция yasno-digest в Yandex Cloud ──► читает digest.json из бакета
```

Почему дайджест собирается не в Yandex Cloud: облако находится в России, и оттуда
не открываются Telegram (t.me и api.telegram.org) и Gemini («User location is not
supported»). Это проверено. Поэтому в Yandex Cloud работает только навык, ему
хватает бакета. GitHub Actions не используется: запуски в этом аккаунте висят в
очереди, а расписание из `.github/workflows/digest.yml` убрано, чтобы не было
двойных публикаций. Ручной запуск там остался.

## Еженедельная задача

Задача Claude Code «Ясно Понятно: еженедельный дайджест» каждое воскресенье
запускает новый облачный сеанс в этом окружении и выполняет:

```bash
pip install -r requirements.txt
DIGEST_BUCKET=yasno-digest-3f3isb47 IS_TEST=false DIGEST_DAYS=7 python main.py
```

Если заданы `DIGEST_BUCKET` и `YC_SA_KEY`, `main.py` после публикации сам загружает
`digest.json` в бакет (`yc_storage.py`: ключ сервисного аккаунта → JWT PS256 → IAM-токен).
Задачу можно посмотреть, поставить на паузу или удалить на claude.ai/code в разделе
со scheduled tasks.

## Как подключить навык (один раз, ~5 минут)

1. Откройте [dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer) под тем
   же аккаунтом Яндекса, где колонка и Yandex Cloud.
2. Нажмите **Создать диалог** → **Навык в Алисе**.
3. **Название навыка**: «Ясно Понятно». С этих слов навык будет запускаться:
   «Алиса, запусти навык Ясно Понятно».
4. **Backend** → **Функция в Яндекс Облаке** → в списке выберите **yasno-digest**.
5. **Доступ** → **Приватный**. Навык будет только у вас, в каталог он не попадёт.
6. Остальные обязательные поля (описание, иконка, категория, email) заполните как
   угодно, это не влияет на работу.
7. Нажмите **Сохранить**, откройте вкладку **Тестирование** и напишите «что нового».
   Должен прийти пересказ дайджеста.
8. Нажмите **Опубликовать**. Приватный навык проходит быструю автоматическую проверку.

После публикации навык доступен на всех колонках вашего аккаунта Яндекса.

## Что умеет навык

| Фраза | Ответ |
|---|---|
| «Алиса, запусти навык Ясно Понятно» | Приветствие и интро недели |
| «Что нового» / «Перескажи неделю» | Весь дайджест по рубрикам |
| «Для бизнеса», «Для маркетологов», «ИИ-тренды», «На подумать» | Одна рубрика |
| «Последний пост» | Начало самого свежего поста |
| «Дальше» / «Повтори» | Следующая часть / повтор (Алиса говорит не больше 1024 символов за раз) |
| «Что ты умеешь» | Подсказка |
| «Хватит» | Выход |
