# Навык Алисы «Ясно Понятно»

Голосовой навык для колонки с Алисой: пересказывает еженедельный дайджест канала @yasnovolkova.

## Как это работает

1. По воскресеньям GitHub Action (`.github/workflows/digest.yml`) генерирует дайджест и публикует его в Telegram.
2. Заодно `voice_export.py` превращает HTML-дайджест в голосовую версию и сохраняет в `alice/digest.json`, а Action коммитит этот файл в репозиторий.
3. Навык (`alice_skill/index.py`) работает в Yandex Cloud Functions, читает `alice/digest.json` и отвечает Алисе. Gemini при этом не вызывается, поэтому ответ приходит мгновенно.

## Что умеет навык

| Фраза | Ответ |
|---|---|
| «Алиса, запусти навык Ясно Понятно» | Приветствие и интро недели |
| «Что нового» / «Перескажи неделю» | Весь дайджест по рубрикам |
| «Для бизнеса», «Для маркетологов», «ИИ-тренды», «На подумать» | Одна рубрика |
| «Последний пост» | Начало самого свежего поста |
| «Дальше» / «Повтори» | Следующая часть / повтор (Алиса говорит не больше 1024 символов за раз) |
| «Что ты умеешь» | Подсказка |
| «Хватит» | Выход |

## Развёртывание (один раз, ~15 минут)

### 1. Получить первый `alice/digest.json`

Смёрджите эту ветку в `main`, затем во вкладке **Actions → Telegram Auto Digest → Run workflow** запустите workflow вручную. После этого в репозитории появится файл `alice/digest.json`.

> Если workflow упадёт на шаге «Save digest for Alice skill» с ошибкой прав: **Settings → Actions → General → Workflow permissions → Read and write permissions**.

### 2. Создать облачную функцию

1. Зайдите в [console.yandex.cloud](https://console.yandex.cloud) → **Cloud Functions** → **Создать функцию**, например `yasno-alice`.
2. **Редактор**: среда выполнения **Python 3.12**, способ — «Редактор кода». Создайте файл `index.py` и вставьте содержимое `alice_skill/index.py`.
3. **Точка входа**: `index.handler`. Таймаут: 5 секунд (как в официальном примере Yandex Cloud). Память: 128 МБ.
4. **Переменные окружения**:
   - `DIGEST_URL` = `https://raw.githubusercontent.com/wz9n5xxyff-commits/tg_summ/main/alice/digest.json`
   - `GITHUB_TOKEN` нужен, только если репозиторий **приватный**. Создайте fine-grained token на GitHub с доступом *Contents: Read-only* к этому репозиторию.
5. Нажмите **Сохранить изменения**.

### 3. Зарегистрировать навык

1. Зайдите в [dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer) → **Создать диалог** → **Навык**.
2. **Название**, например «Ясно Понятно». Это фраза активации: «Алиса, запусти навык Ясно Понятно».
3. **Backend**: «Функция в Яндекс Облаке» → выберите `yasno-alice`.
4. **Доступ**: выберите **приватный** навык. Он не попадёт в каталог и будет доступен только вам.
5. Проверьте навык во вкладке **Тестирование** и нажмите **Опубликовать**. Приватный навык проходит автоматическую модерацию с минимальными требованиями, а публичный — полную ручную. Пока навык на модерации, его нельзя редактировать, но его можно вернуть в черновик.

После публикации навык доступен на всех колонках вашего аккаунта Яндекса.
