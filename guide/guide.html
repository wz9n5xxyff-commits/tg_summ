1Придумайте, что будет отвечать навык

Выпишите вопросы, которые будут задавать колонке, и что она должна ответить. Например, для расписания ребёнка:

СпрашиваютАлиса отвечает
«Что во вторник?»Во вторник с 16:30 до 17:30 танцы.
«Когда танцы?»Танцы во вторник и четверг в 16:30.
«Что сегодня?»Ответ зависит от дня недели. Такое умеет код, который напишет ИИ.

Придумайте и название навыка. С него навык будет запускаться: «Алиса, запусти навык Расписание дочки».

2Получите код навыка

Вариант А: попросите ИИ. Скопируйте в Claude (или другой ИИ) такой запрос и допишите свои вопросы и ответы:

Напиши навык для Алисы на Python для Yandex Cloud Functions. Один файл index.py, точка входа index.handler, без сторонних библиотек. Навык отвечает на такие вопросы: [ваша таблица из шага 1]. На «что сегодня» и «что завтра» отвечай по текущему дню недели по московскому времени. Объясни простыми словами, куда вставить код.

Вариант Б: возьмите готовый пример и поменяйте ответы на свои (текст в кавычках):

ANSWERS = {
    "понедельник": "В понедельник с 17:00 до 19:00 логоритмика.",
    "вторник": "Во вторник с 16:30 до 17:30 танцы.",
    "танц": "Танцы во вторник и четверг в 16:30.",
}

def handler(event, context):
    text = event["request"]["command"].lower()
    if not text:
        reply = "Привет! Спросите про день недели или занятие."
    else:
        reply = "Не поняла. Спросите, например: что во вторник?"
        for word, answer in ANSWERS.items():
            if word in text:
                reply = answer
                break
    return {
        "version": event["version"],
        "response": {"text": reply, "end_session": False},
    }
Слева в кавычках слово, которое ищем во фразе, справа ответ. «танц» без окончания ловит и «танцы», и «танцах». Сохраняйте пробелы в начале строк.

3Создайте функцию в Яндекс Облаке

console.yandex.cloud→войти аккаунтом Яндекса
  1. Если заходите впервые, Облако предложит создать платёжный аккаунт. Привяжите карту. Это нужно, чтобы облако заработало; деньги за маленький навык обычно не списываются.
  2. В меню слева (или через поиск сервисов) откройте Cloud Functions.
  3. Нажмите Создать функцию.
  4. Имя: латиницей, маленькими буквами, без пробелов, например raspisanie. Нажмите Создать.

4Вставьте код

Cloud Functions→ваша функция→Редактор
  1. Среда выполнения: Python 3.12. Нажмите Продолжить.
  2. Способ: Редактор кода. Нажмите Создать файл и назовите его index.py.
  3. Вставьте в файл код из шага 2.
  4. Ниже заполните параметры:
    Точка входаindex.handler
    Таймаут3 секунды
    Память128 МБ
  5. Нажмите Сохранить изменения и подождите, пока появится версия функции.
Делать функцию публичной не нужно: Яндекс Диалоги вызовут её сами, когда вы подключите навык.

5Подключите навык к Алисе

dialogs.yandex.ru/developer→тем же аккаунтом Яндекса
  1. Нажмите Создать диалог и выберите Навык в Алисе.
  2. Название навыка: то, что придумали в шаге 1, например Расписание дочки.
  3. Backend: выберите Функция в Яндекс Облаке и в списке свою функцию (raspisanie).
  4. Доступ: Приватный. Навык будет только у вас, проверка быстрая и автоматическая.
  5. Заполните карточку: короткое описание, 2–3 примера запросов («что сегодня», «когда танцы»), квадратная картинка-иконка, ваша почта, категория. На работу навыка это не влияет.
  6. Нажмите Сохранить.

6Проверьте и опубликуйте

  1. Откройте вкладку Тестирование и напишите в окне вопрос, например «что во вторник». Должен прийти ваш ответ.
  2. Если всё правильно, нажмите Отправить на модерацию.
  3. Ждите, пока статус сменится на «Опубликован». Обычно это от нескольких минут до суток.
Окно в «Тестировании» — это разговор с самим навыком. Если написать туда «опубликовать», навык ответит «не поняла». Публикуется навык кнопкой, а не фразой.

7Говорите с колонкой

«Алиса, запусти навык Расписание дочки»навык поздоровается и будет ждать вопросов
«Алиса, спроси у навыка Расписание дочки, что во вторник»ответит сразу, одной фразой
«Хватит»выйти из навыка

Если что-то не получилось

Что происходитЧто сделать
Навык отвечает «Не поняла» на всёПроверьте, что слово из вопроса есть в коде. Пишите его без окончания: «танц», а не «танцы».
В «Тестировании» ошибка или тишинаПроверьте в Облаке точку входа: index.handler, а файл называется index.py. После правок нажмите Сохранить изменения.
В Диалогах нет вашей функции в спискеСкорее всего, вы вошли другим аккаунтом Яндекса. И Облако, и Диалоги должны быть под одним аккаунтом.
Хочу поменять ответыПоправьте текст в коде в Облаке и сохраните. Навык заново публиковать не нужно.
Модерация отклонила навыкЯндекс пишет причину. Обычно это незаполненное поле карточки или неподходящая иконка.
Колонка не находит навыкПроверьте, что статус «Опубликован» и колонка привязана к тому же аккаунту. Название произносите точно так, как написали.
